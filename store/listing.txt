EXTENSION NAME:
TabKebab

SHORT DESCRIPTION (132 chars max):
Stack and Organize Tabs — group by domain or AI, save sessions, close duplicates, and organize with drag-and-drop.

DETAILED DESCRIPTION:
TabKebab is a side panel extension that tames tab chaos. Group, stash, sleep, and restore tabs across windows — manually or with AI.

🎯 FOCUS MODE
• Time-bounded productivity sessions with distraction blocking
• 4 built-in profiles: Coding, Writing, Research, Meeting
• Live countdown timer with profile-colored HUD
• Blocks navigation to distracting sites (YouTube, Reddit, social media)
• Three blocking modes: Strict (whitelist only), Curated Categories, AI Detection
• Flexible allowlist for domains, URLs, and Chrome tab groups
• Session reports with stats and focus history

🗂 ORGANIZE
• Group tabs by domain into native Chrome tab groups with one click
• AI-powered smart grouping that understands context (research, shopping, work)
• Drag-and-drop custom groups with color coding
• Consolidate scattered windows into fewer, organized ones

📦 STASH
• Save and close tabs by window, Chrome group, or domain
• Tabs are offloaded to local IndexedDB — no cloud, no size limits
• Restore later in discarded mode so tabs don't all load at once
• Favicon previews, source badges, and one-click restore or delete

💾 SESSIONS
• Save full snapshots of every window, tab, and group layout
• Restore with automatic deduplication — already-open tabs are skipped
• Auto-saves on browser start and every 24 hours, keeping the last 2
• Per-session export for sharing or backup

😴 TAB SLEEP (KEBAB)
• Discard tabs to free memory while keeping them in the tab strip
• Per-domain keep-awake exceptions (email, calendars, AI tools protected by default)
• AI-assisted classification suggests which domains to protect
• Sleep by domain, group, window, or everything at once

🔍 FIND & CLEAN
• Duplicate detection and bulk close across all windows
• Empty pages cleanup (about:blank, new tabs)
• Natural language commands: "close YouTube tabs", "find my GitHub tabs", "group by project"

📤 EXPORT & SYNC
• Full JSON export/import of sessions, stashes, groups, and settings
• Individual session and stash exports
• Google Drive sync (optional)

🤖 AI PROVIDERS (all optional, bring your own key)
• OpenAI (GPT-6, GPT-5, GPT-4.1)
• Anthropic Claude (Haiku, Sonnet, Opus)
• Google Gemini (2.5 Flash/Pro, 3.0 preview)
• Chrome Built-in AI (Gemini Nano, on-device, no API key needed)
• Any OpenAI-compatible endpoint (Ollama, LM Studio, Groq, Together AI)

🔒 PRIVACY
• Zero data collection — no telemetry, no analytics, no tracking
• Everything stored locally unless you explicitly opt in to AI or Drive
• API keys encrypted with AES-GCM 256-bit
• Full privacy policy: https://tabkebab.com/privacy
